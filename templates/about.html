About SIGO AI

🎯 Objectives

The system helps businesses identify risky vendors using Machine Learning models trained on procurement and supplier performance data. SIGO AI improves procurement efficiency, reduces operational failures, and enables organizations to make smarter supplier decisions through predictive analytics.

🤖 Models Used

Random Forest is used for vendor risk classification, while Logistic Regression estimates vendor failure probability. These models analyze procurement behavior, dispute trends, delivery performance, and vendor reliability patterns.

🛠 Technologies

Python, Flask, Pandas, NumPy, Scikit-learn, HTML, CSS, JavaScript, Chart.js, and Machine Learning technologies were used to develop the complete AI-powered procurement intelligence platform.

📊 Key Features

• Vendor Risk Prediction using AI

• Real-time Procurement Analytics Dashboard

• Interactive Risk Probability Meter

• Smart Vendor Performance Evaluation

• Machine Learning Based Decision Support System
